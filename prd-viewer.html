1. 产品概述

1.1 产品背景

魔乐学堂是魔乐社区旗下的AI学习平台，旨在为AI开发者、研究人员和学习者提供高质量的在线课程学习服务。平台汇聚了AI领域的优质讲师资源，提供视频课程、文本课程和混合课程等多种学习形式。

1.2 产品定位

  • 目标用户：AI开发者、研究人员、高校学生、AI爱好者
  • 核心价值：提供专业、系统化的AI学习资源
  • 产品特色：结合魔乐社区生态，支持模型、数据、工具等一站式学习

1.3 产品架构

│   ├── 封面、免费/收费标签

2. 用户角色

2.1 普通用户（学员）

  • 浏览和搜索课程
  • 加入学习课程
  • 提交课程作业
  • 参与课程讨论
  • 查看学习进度

2.2 讲师

  • 上传和发布课程
  • 发布课程作业
  • 审批学员作业
  • 查看学员提交记录
  • 管理课程内容
  • 兼并普通用户角色

2.3 管理员

  • 课程审核
  • 讲师认证管理
  • 标签管理
  • 平台内容管理

3. 功能模块详细设计

3.1 首页模块

3.1.1 页面布局

  • 顶部导航栏：放在一级菜单"社区"下，和活动赛事同为二级菜单，排序在活动赛事后
  • 页面标题区：页面标题、上传课程按钮
  • 主内容区：左侧筛选栏 + 右侧课程列表

3.1.2 课程筛选（后台全可配置）

筛选项 选项值
课程类型 免费课程、付费课程
任务类型 自然语言处理、计算机视觉、多模态、音频处理
难度级别 社区教程、入门教程、进阶教程、高级教程
学习时长 <10min、10-30min、30-60min、>60min

3.1.3 课程卡片

  • 课程封面图
  • 课程类型标签（免费/付费）
  • 课程标题
  • 难度级别标签
  • 时长统计
  • 讲师头像和姓名
  • 学习人数

3.2 课程详情页

3.2.1 上部区域

左侧 - 播放器/阅读器

  • 视频课程：视频播放器、进度条、时间显示
  • 文本课程：文本阅读器、字体大小调整、全屏阅读
  • 混合课程：支持视频和文本切换

右侧 - 课程信息

  • 课程名称
  • 互动按钮（点赞、收藏、分享）
  • 课程统计（播放量、学习人数、章节数、总时长）
  • 学习进度
  • 加入学习按钮

3.2.2 下部区域

左侧Tab页

  1. 课程详情 - 课程简介、课程大纲（章节列表）
  2. 课程作业（详细见3.2.3）- 已发布作业列表、查看我的提交（通过/待审核/不通过）、查看所有提交（讲师视角）
  3. 讨论区 - 评论输入框、评论列表

右侧模块

  • 授课讲师卡片（头像、姓名、职位、课程数、学员数）
  • 推荐课程列表（默认8门），取学习人数前8课程即可

3.2.3 课程作业功能

作业列表

  • 作业标题
  • 作业描述
  • 截止日期
  • 状态（进行中/已结束）
  • 已提交人数

提交作业

  • 文本内容输入
  • 附件上传（支持PDF等格式）
  • 提交确认

作业审批（讲师视角）

  • 查看所有学员提交
  • 提交详情查看
  • 通过/不通过操作

证书下载

  • 审核通过后可下载证书
  • 证书内容包含：课程名称、学员名字、证书编号、证书获取时间、证书有效时间
  • 例如：***课程完结证书

3.3 讲师模块

3.3.1 讲师详情页面

  • 讲师基本信息（头像、名字、职位、课程数、学员数、总播放量、描述）
  • 讲师课程列表

3.4 课程上传模块

3.4.1 上传步骤

  1. 基本信息 - 章节结构选择（新课程/已有课程）、课程封面上传、课程类型、课程标题、任务类型选择、难度级别选择
  2. 课程内容 - 视频上传/文本内容输入（PDF）
  3. 发布设置 - 课程价格设置（免费/付费）、预计学习时长、课程作业配置（作业标题、作业描述、作业附件）、发布选项（立即发布、允许学员评论、启用作业评审、启用证书发放）、协议确认

3.4.2 课程作业配置

  • 作业标题
  • 截止日期
  • 作业描述
  • 作业附件上传
  • 添加多个作业

3.5 后台管理模块

3.5.1 课程管理

功能列表

  • 课程列表展示（表格形式）
  • 课程筛选（状态、类型、难度）
  • 课程搜索
  • 课程审核（通过/驳回）
  • 课程编辑
  • 课程删除

课程状态

  • 待审核
  • 已通过
  • 已驳回
  • 已发布

3.5.2 讲师管理

功能列表

  • 讲师列表展示
  • 讲师搜索
  • 添加讲师（用户名下拉选择）
  • 编辑讲师信息
  • 移除讲师
  • 讲师详情查看

讲师信息

  • 用户名
  • 职位
  • 简介
  • 课程数
  • 学员数
  • 总播放量
  • 状态（已认证/未认证）

3.5.3 标签管理

功能列表

  • 大类标签管理
  • 子标签管理
  • 新增标签
  • 编辑标签
  • 删除标签

标签层级

  • 一级标签：任务类型（NLP、CV、多模态等）
  • 二级标签：具体技术（深度学习、Transformer等）

4. 交互设计

4.1 页面跳转逻辑

首页 → 课程详情页（点击课程卡片）
首页 → 全部讲师（点击"查看全部"）
首页 → 上传课程（点击"上传课程"按钮）
课程详情页 → 讲师详情（点击讲师卡片）
课程详情页 → 课程详情（点击推荐课程）
全部课程 → 讲师详情（点击讲师卡片）
后台管理 → 课程管理/讲师管理/标签管理（侧边栏导航）

4.2 弹窗交互

  • 上传课程弹窗（多步骤表单）
  • 作业提交弹窗
  • 作业审批弹窗
  • 确认操作弹窗

4.3 状态反馈

  • 操作成功提示（Toast）
  • 加载状态
  • 错误提示
  • 确认对话框
